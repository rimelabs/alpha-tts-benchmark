# AlphaTTSBench 1.0.0 release

SupportBench supports preference for Rime over all four configured competitors. ContentBench supports preference for Rime over Cartesia and OpenAI, and for Deepgram and ElevenLabs over Rime. AlphaBench provides qualitative evidence, not a provider ranking. See the [results](results/README.md).

The main-study results contain **31,100 judgments**. The separate Alpha pilot adds **1,350**, bringing the full run to **32,450**. The pilot is excluded from the website's main-study count.
